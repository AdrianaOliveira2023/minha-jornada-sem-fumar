# 🚭 Minha Jornada Sem Fumar

Um projeto pessoal criado para acompanhar meu processo de parar de fumar.

Desenvolvi o aplicativo com a ajuda do **GPT**: dei as ideias e comandos, e o GPT gerou os códigos que fui testando e ajustando ao longo do projeto.

A proposta é simples: acompanhar o tempo sem fumar, as conquistas, os cigarros evitados, o dinheiro economizado e os benefícios dessa nova fase.

**Um dia de cada vez. Uma conquista de cada vez. 🌱**
